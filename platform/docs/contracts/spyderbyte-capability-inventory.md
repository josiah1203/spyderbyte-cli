# Spyderbyte capability inventory

Status: Phase 0 acceptance artifact, updated 2026-08-06.

This is the visible-capability inventory for the local-first product. The classification is about
what a user can truthfully rely on today, not whether a screen or route exists. The authoritative
route list is `apps/api/contracts/api.v1.json`; the local implementation is
`packages/local-api/src/index.ts`; the client surfaces are `packages/client-sdk`, `apps/tui`,
`apps/web`, `apps/desktop`, and `packages/jupyter-extension`.

## Classification

- `real`: invokes an implemented adapter or authoritative state transition and exposes its result.
- `projection-only`: reads a durable projection but does not claim to execute the underlying work.
- `mocked`: deterministic fixture behavior used for development or contract tests.
- `local-only`: implemented only in the local runtime boundary.
- `experimental`: implemented behind an explicit capability/adapter gate and not part of the first
  durable loop.
- `incomplete`: a visible design or route exists, but the backend cannot complete the operation.

## Existing entry points covered by this inventory

- API and local API: route manifests plus `apps/api/src` and `packages/local-api/src`.
- TUI/CLI: `apps/tui/src/index.ts` and `apps/local-daemon/src/cli.ts`.
- Web/desktop actions: `apps/web/src/runtime/page-registry.ts`, screen components, and the Tauri
  host in `apps/desktop/src-tauri`.
- Provider actions and runtimes: `packages/provider-runtime/src/provider-actions.ts`,
  `providers.ts`, `connections.ts`, `connector-registry.ts`, `query.ts`, `notebook.ts`,
  `repositories.ts`, `runtime-profiles.ts`, `jupyter.ts`, `pipelines.ts`, `automations.ts`,
  `training.ts`, `serving.ts`, and `visualizations.ts`.
- Contract authority and fixtures: `packages/runtime-contracts/src`, its JSON Schema, generated
  outputs, and `packages/runtime-contracts/tests/fixtures.ts`.

Any new visible action must add a row here, a capability descriptor when gated, a route/command
entry in `spyderbyte-command-map.md`, and a fixture or focused test proving its authority boundary.
